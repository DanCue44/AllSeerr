# Unraid

## Community Applications (recommended)

AllSeerr has a template in Unraid's Community Applications.

1. Open the **Apps** tab and search for **AllSeerr**.
2. Click **Install**. The template uses the image `ghcr.io/dancue44/allseerr:latest`, port `5055` and stores its data in `/mnt/user/appdata/allseerr` (mounted at `/app/config`).
3. Set **TZ** to your [time zone](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) and click **Apply**.
4. Open the WebUI at `http://<your-unraid-ip>:5055` and follow the setup wizard.

To try the testing channel, change the repository tag from `latest` to `develop`. See [Update Channels](/getting-started/update-channels).

## Manual Installation

If you prefer to add the container by hand, first choose which user the container runs as:

**AllSeerr Default** (`UID 1000:1000`): runs as the image's own `node` user. This matches the image, but may break SMB share access, trigger "Fix Common Problems" warnings, and cause issues with backup plugins (such as CA Appdata Backup).

**Unraid Default** (`UID 99:100`): runs as Unraid's `nobody:users`. This follows Unraid conventions, but overrides the image's built-in user.

<Tabs groupId="unraid-permissions" queryString>
  <TabItem value="allseerr-default" label="AllSeerr Default">

  ### 1. Create the config directory

  Open the Unraid terminal and run:

  ```bash
  mkdir -p /mnt/user/appdata/allseerr
  chown -R 1000:1000 /mnt/user/appdata/allseerr
  ```

  ### 2. Add the Docker container

  :::warning
  The **Extra Parameters** field is critical. You **must** add `--init --restart=unless-stopped`. Without `--init`, the container will not handle signals properly or shut down cleanly. Without `--restart=unless-stopped`, the container will not restart after a reboot.

  To see the **Extra Parameters** field, click **Basic View** in the top-right corner of the template page to switch to the advanced editor.
  :::

  Navigate to the **Docker** tab in Unraid and click **Add Container**. Fill in the following:

  | Field | Value |
  |---|---|
  | **Name** | `AllSeerr` |
  | **Repository** | `ghcr.io/dancue44/allseerr:latest` |
  | **Icon URL** | `https://raw.githubusercontent.com/DanCue44/AllSeerr/main/public/android-chrome-512x512.png` |
  | **WebUI** | `http://[IP]:[PORT:5055]` |
  | **Extra Parameters** | `--init --restart=unless-stopped` |
  | **Network Type** | `bridge` |
  | **Privileged** | `Off` |

  Then click **Add another Path, Port, Variable** to add:

  | Type | Container | Host / Value |
  |---|---|---|
  | Port (TCP) | `5055` | `5055` |
  | Path | `/app/config` | `/mnt/user/appdata/allseerr` |
  | Variable | `TZ` | Your time zone, e.g. `America/New_York` |
  | Variable (optional) | `LOG_LEVEL` | `info` |

  Click **Apply** to create and start the container, then open `http://<your-unraid-ip>:5055`.
