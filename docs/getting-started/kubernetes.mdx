# Kubernetes
:::warning
This method is not recommended for most users. It is intended for advanced users who are using Kubernetes.
:::

:::info
AllSeerr does not publish a Helm chart. Seerr's chart works if you point its image at `ghcr.io/dancue44/allseerr`, or use a plain Deployment like any other single container app.
:::

## Installation
```console
helm install allseerr oci://ghcr.io/seerr-team/seerr/seerr-chart \
  --set image.registry=ghcr.io \
  --set image.repository=dancue44/allseerr \
  --set image.tag=latest
```

Check Seerr's chart `values.yaml` for the exact image keys and the other values. The container listens on port `5055` and keeps its data in `/app/config`, so give it a persistent volume there.
