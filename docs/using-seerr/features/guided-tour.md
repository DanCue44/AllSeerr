# Guided Tour

The guided tour is a short, step by step look at the Ambient interface. It takes about a minute and shows users where everything is: the For You home page, the spaces for movies, series, music and books, search, the Library, the Calendar, how to request something (including picking seasons, or choosing ebook, audiobook or both), tracking requests, the watchlist, reporting issues and their account menu.

The tour only mentions what your server offers. For example, it leaves out books when no book service is set up, and mentions subtitles only when Bazarr is connected.

## When it opens

- It opens **once, by itself**, for every user who has not seen it yet, the first time they use the Ambient interface after signing in.
- That it was seen is stored with the user, not in the browser, so it does not show again on their other devices.
- Users who used the app before see a "Been here before?" step that points out what is new.
- Users can **Skip** at any step.

## Taking it again

Anyone can take the tour again from **Take the Tour** in the user menu, or from **Settings &rarr; General &rarr; Guided Tour** in their own profile.

The tour is part of the Ambient interface. Users on the classic interface do not see it.
